# QWEMU MUSIC Desktop

**QWEMU MUSIC 2.0 — Infinity Evolution** — локальный музыкальный центр для Windows 10/11.  
**Версия:** 2.0.0 · **Стек:** Tauri 2.12.7 · Rust · HTML/CSS/JavaScript · WebView2.

## Что входит в 2.0

### Музыкальная библиотека
- MP3, WAV, FLAC, OGG/OGA, M4A, AAC, OPUS, WEBM audio, MP4 audio, 3GP и M4B. Реальная поддержка зависит от Windows WebView2 и установленных кодеков.
- Локальная IndexedDB-медиатека: до 5000 записей, до 512 МиБ на файл и 2 ГиБ суммарно.
- Последовательный импорт, дедупликация по fingerprint, обработка сбоев отдельных файлов без остановки всего импорта.
- Редактирование названия, исполнителя, альбома и текстов песен; TXT/LRC, синхронизация строк и переход по тайм-кодам.
- Поиск, сортировка, избранное, история, плейлисты и M3U8 import/export.
- Library Studio: массовый выбор треков, пакетные операции с очередью/плейлистами/избранным, экспорт выбранных композиций и атомарное удаление.

### Воспроизведение и звук
- Устойчивое переключение треков с отменой устаревших асинхронных запросов.
- Очередь, shuffle, repeat, управление горячими клавишами и MediaSession там, где это поддерживает WebView.
- **Возобновление последней сессии:** очередь, текущая композиция, позиция, shuffle и repeat сохраняются локально; пользователь сам запускает продолжение. Повторный запуск без нажатия «Продолжить» не сбрасывает точку, а ручное редактирование очереди сохраняется.
- 10-полосный эквалайзер, 6 пресетов, пользовательские настройки и защита от клиппинга.
- Отдельный аудиоканал для cross-origin потоков: ограничения CORS не должны заглушать прямой поток, но EQ для таких потоков может быть недоступен.

### Ссылки и сервисы
- Каталог из 26 музыкальных платформ: YouTube Music, Spotify, Apple Music, SoundCloud, Bandcamp, Deezer, TIDAL, Audiomack, Mixcloud, Amazon Music, Qobuz, Last.fm, Pandora, Jamendo, Audius, Free Music Archive, hearthis.at, ReverbNation, Яндекс Музыка, VK Музыка, Звук, МТС Музыка, Anghami, Boomplay, JioSaavn и KKBOX.
- Ссылки платформ сохраняются как закладки и открывают оригинальный сервис. QWEMU не обходит DRM, не извлекает закрытые потоки и не скачивает защищённый контент.
- Прямые HTTPS-ссылки на поддерживаемые аудиоформаты могут воспроизводиться как потоки.

### Резервное копирование и обновления
- Экспорт/импорт JSON-копии метаданных медиатеки, плейлистов, избранного, истории, общих настроек и пользовательской 10-полосной EQ-кривой.
- Резервная копия не содержит аудиобайты. Восстановление сопоставляет локальные треки по ID, объединяет избранное/плейлисты/историю без удаления более новых записей; отсутствующие локальные файлы нужно импортировать заново. Ссылки повторно проверяются, старые URL платформ мигрируют в закладки.
- Проверка версии при запуске и вручную по публичному GitHub Releases и манифесту.
- Обновление не устанавливается скрытно: пользователь открывает официальный релиз GitHub и сам запускает EXE/MSI.
- QWEMU PLUS — DEMO: визуальная демонстрация, не подписка, не платный каталог и не реальные результаты поиска.

## Приватность и хранение
Аудиофайлы и локальные настройки остаются на устройстве. Desktop Edition не требует аккаунта и не отправляет локальные аудиофайлы в облако. Облачная авторизация относится к отдельной Web Edition; здесь локальная библиотека хранится в IndexedDB профиля приложения.

## Сборка Windows

Требуются Windows 10/11 x64, Node.js 22+, Rust stable MSVC, Visual Studio Build Tools с C++ workload и WebView2 Runtime.

Из корня проекта:
- `run.bat` — запуск dev;
- `check.bat` — frontend/unit/smoke проверки;
- `build.bat` — Windows NSIS EXE и MSI.

**BAT-файлы в обновлении 2.0 не менялись.** Сборка CI дополнительно проверяет наличие обоих установщиков и публикует их как GitHub Actions artifact; тег `v2.0.0` запускает workflow публикации GitHub Release.

## Проверки проекта
`npm run check` выполняет синтаксические проверки модулей, unit-тесты, smoke-проверки интеграции и синхронизацию версии в `package.json`, Cargo, Tauri и HTML. Для Rust дополнительно выполняется `cargo fmt --check`; Windows CI строит NSIS EXE и MSI.
