# QWEMU MUSIC Desktop

**Локальный музыкальный плеер Windows 10/11.**  
Версия **1.8.0** · Tauri 2.12.7 · Rust · HTML/CSS/JavaScript

## Возможности
- MP3, WAV, FLAC, OGG/OGA, M4A, AAC, OPUS, WEBM audio, MP4 audio, 3GP и M4B (поддержка зависит от WebView2/кодеков Windows).
- Защита от гонок при быстром переключении композиций: устаревшие запросы чтения аудио больше не могут перезапустить предыдущий трек.
- Локальная IndexedDB-медиатека (2 GiB, 512 MiB на файл), плейлисты, избранное, история, поиск и очередь.
- Последовательный импорт файлов: исключение дублей при повторном выборе, независимая обработка ошибок каждого файла и итоговая сводка.
- 10-полосный EQ, 6 пресетов, индивидуальная настройка и защита от клиппинга.
- Текст песни: прикрепить TXT или LRC, редактировать, синхронизировать по временным меткам LRC, подсветка строки и переход к её времени.
- Фоновое воспроизведение с системными MediaSession-кнопками там, где WebView/браузер поддерживает их. По умолчанию включено; можно отключить в настройках.
- Добавление по ссылке: каталог из 26 платформ (YouTube Music, Spotify, Apple Music, SoundCloud, Bandcamp, Deezer, TIDAL, Audiomack, Mixcloud, Amazon Music, Qobuz, Last.fm, Pandora, Jamendo, Audius, Free Music Archive, hearthis.at, ReverbNation, Яндекс Музыка, VK Музыка, Звук, МТС Музыка, Anghami, Boomplay, JioSaavn и KKBOX). Список отображается в форме импорта; ссылка автоматически определяет сервис и сохраняется локально с его метаданными.
- QWEMU PLUS — DEMO: только демонстрационный UI, не подписка, не платный каталог, не реальные результаты поиска.
- Скрытая в «Настройки → О программе» ручная проверка версии. Автоматическое скачивание/установка обновлений не выполняется.
- Редизайн кнопок плеера и выбранный QWEMU Music логотип.
- Windows NSIS EXE и MSI; локальные файлы остаются на устройстве.

## Поддерживаемые ссылки
QWEMU распознаёт 26 музыкальных платформ из каталога в окне импорта. Ссылки на эти сайты сохраняются как закладки и открываются через оригинальный сервис; QWEMU не извлекает защищённые потоки и не скачивает контент с платформ. Прямые HTTPS-ссылки на MP3/WAV/FLAC/OGG/M4A/AAC/OPUS/WEBM/MP4/3GP/M4B воспроизводятся внутри плеера. Внешние потоки используют отдельный аудиоканал, чтобы Web Audio EQ не заглушал звук из-за ограничений cross-origin/CORS. Эквалайзер работает с локальными файлами и совместимыми same-origin источниками.

## Сборка
Требуются Windows 10/11 x64, Node.js 22+, Rust stable MSVC, Visual Studio Build Tools (C++), WebView2 Runtime.

- `run.bat` — запуск dev
- `build.bat` — EXE/MSI
- `check.bat` — проверки

Скрипты BAT в этом обновлении не редактировались.
