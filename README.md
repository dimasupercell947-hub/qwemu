# QWEMU MUSIC Desktop

**Локальный музыкальный плеер Windows 10/11.**  
Версия **1.7.0** · Tauri 2 · Rust · HTML/CSS/JavaScript

## Возможности
- MP3, WAV, FLAC, OGG/OGA, M4A, AAC, OPUS, WEBM audio, MP4 audio, 3GP и M4B (поддержка зависит от WebView2/кодеков Windows).
- Локальная IndexedDB-медиатека (2 GiB, 512 MiB на файл), плейлисты, избранное, история, поиск и очередь.
- 10-полосный EQ, 6 пресетов, индивидуальная настройка и защита от клиппинга.
- Текст песни: прикрепить TXT или LRC, редактировать, синхронизировать по временным меткам LRC, подсветка строки и переход к её времени.
- Фоновое воспроизведение с системными MediaSession-кнопками там, где WebView/браузер поддерживает их. По умолчанию включено; можно отключить в настройках.
- Добавление по HTTPS-ссылке: прямые аудиоссылки сохраняются как поток; распознанные музыкальные сайты — как закладки. Ссылки проверяются, скачивание/извлечение с музыкальных платформ не выполняется.
- QWEMU PLUS — DEMO: только демонстрационный UI, не подписка, не платный каталог, не реальные результаты поиска.
- Скрытая в «Настройки → О программе» ручная проверка версии. Автоматическое скачивание/установка обновлений не выполняется.
- Редизайн кнопок плеера и выбранный QWEMU Music логотип.
- Windows NSIS EXE и MSI; локальные файлы остаются на устройстве.

## Поддерживаемые ссылки
Прямые ссылки на аудиофайлы с HTTPS и URL известных музыкальных платформ могут быть сохранены. Для платформенных URL запись добавляется как внешняя закладка, поскольку QWEMU не извлекает защищённые потоки и не загружает музыку с таких сайтов. Доступность прямого потока зависит от источника, его политики и WebView2.

## Сборка
Требуются Windows 10/11 x64, Node.js 22+, Rust stable MSVC, Visual Studio Build Tools (C++), WebView2 Runtime.

- `run.bat` — запуск dev
- `build.bat` — EXE/MSI
- `check.bat` — проверки

Скрипты BAT в этом обновлении не редактировались.
