# QWEMU MUSIC 1.2.0 — AI Music Finder PRO

## Возможности

- Проверка введённого HTTP(S)-адреса: HTTPS/HTTP, публичный DNS/IP, доступность и HTML content-type.
- Облачный поиск через OpenAI Responses API и `web_search`.
- Ограничение `allowed_domains` задаётся непосредственно в Web Search API. Дополнительно Rust повторно фильтрует URL страниц и прямых аудиофайлов по выбранному домену и его поддоменам.
- Режимы: точные совпадения, расширенный поиск и поиск по альбому/EP.
- Настраиваемое число результатов: 6, 12 или 20; сортировка по соответствию, названию или исполнителю; необязательное включение ремиксов/live/альтернативных версий.
- Карточки результатов показывают название, исполнителя, альбом, длительность, год, жанр, причину совпадения, оценку соответствия и наличие прямого аудиофайла.
- В ответе возвращаются число подтверждённых страниц-источников, выбранная модель, домен и время поиска.
- История последних 12 запросов (адрес, запрос, режим) хранится локально в `localStorage` и может быть очищена пользователем.
- Возможные дубликаты по нормализованным названию и исполнителю помечаются до импорта. Никакие файлы автоматически не удаляются.
- Массовый выбор и снятие выбора результатов.
- Статус настройки облачного ИИ проверяется отдельной командой Rust без передачи API-ключа во frontend.
- Импорт всегда требует явного подтверждения пользователя. Импортируются только доступные прямые аудиофайлы поддерживаемых типов, а не обычные страницы каталога.

## Настройка OpenAI API на Windows

1. Создай API key в панели OpenAI.
2. Открой обычный терминал Windows под своей учётной записью.
3. Выполни `setx OPENAI_API_KEY "ТВОЙ_API_KEY"`.
4. Полностью закрой QWEMU и открой заново. `setx` влияет только на новые процессы.
5. Не отправляй ключ в чаты и не добавляй его в исходники, frontend, ZIP или скриншоты.

По умолчанию используется модель `gpt-6.2-astra`. Можно задать другую доступную модель через переменную среды `QWEMU_AI_MODEL`. В приложении команда «Статус ИИ» показывает только факт наличия ключа и имя модели — само значение ключа не читается frontend.

## Команды Rust

- `qwemu_check_music_site(address)` — проверка URL сайта.
- `qwemu_ai_config_status()` — безопасная проверка наличия настройки ключа и выбранной модели.
- `qwemu_ai_music_search(address, keywords, mode, limit, includeRemixes, sortBy)` — проверка сайта и поиск. Возвращает результаты и метаданные поиска.

## Безопасность и ограничения

- Нужны интернет и доступный API-аккаунт OpenAI. Использование API и Web Search может тарифицироваться согласно настройкам аккаунта.
- Ключ читается только Rust-процессом из `OPENAI_API_KEY`; он не включается в JavaScript или архив исходников.
- В запрос передаётся `store: false`. Это отключает сохранение объекта Responses через этот параметр, но не является обещанием об отсутствии любой обработки данных со стороны провайдера.
- Поиск работает по публичным индексируемым страницам выбранного домена. Он не является универсальным парсером закрытых каталогов.
- Домен фильтруется непосредственно Web Search API, а Rust независимо проверяет возвращённые URL. Сторонние CDN-домены для аудиофайлов намеренно не принимаются — такой файл можно импортировать только через отдельную проверенную ссылку, если её домен соответствует правилам безопасности.
- Страницы, требующие входа, подписки, обхода защиты, DRM или cookie-сессии, не обходятся.
- Результаты, оценка соответствия и метаданные могут содержать ошибки. Проверяй исходную страницу.
- Большинство музыкальных страниц не публикует прямую ссылку на аудиофайл. Их можно открыть в браузере, но они не импортируются как локальный файл.
- Redirects отключены для проверки сайта и аудиозагрузок. Если сайт перенаправляет, вставь конечную публичную ссылку вручную.
- Импорт доступен только для поддерживаемого прямого аудиофайла; загрузчик Rust повторно проверяет URL, MIME, размер и формат.
- История запросов хранится локально в `localStorage` и не содержит API-ключа.

## Проверки

`npm run check` выполняет статические проверки frontend/backend-интеграции и Stage 4 AI Music Finder PRO. Для полной проверки Rust нужны `cargo fmt --check`, `cargo check` и `cargo test` на машине с Rust toolchain. Реальный запрос OpenAI требует пользовательского API-ключа. Windows EXE/MSI, WebView2 и аппаратное воспроизведение должны быть проверены на Windows 10/11.
