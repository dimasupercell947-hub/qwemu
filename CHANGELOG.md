# История изменений QWEMU MUSIC Desktop

## 2.0.0 — Infinity Evolution

### Library Studio и управление данными
- Полный переход на версию 2.0.0 во всех пакетных, Rust/Tauri, HTML и CI-метаданных.
- Массовый выбор композиций в медиатеке, избранном, очереди, истории и открытом плейлисте.
- Пакетное добавление в очередь, плейлисты и избранное без дублирования записей.
- M3U8-экспорт выбранной подборки и пакетное удаление через одну транзакцию IndexedDB.
- Статистика библиотеки: количество записей, избранное, общая известная длительность и объём локального аудиохранилища.

### Playback Continuity
- Добавлено локальное сохранение позиции и очереди воспроизведения, текущей композиции, shuffle и repeat. Точка продолжения сохраняется и при повторном закрытии без запуска; исходная очередь Shuffle остаётся доступной после перезапуска.
- Позиция обновляется с ограничением частоты записи, чтобы не записывать localStorage на каждом `timeupdate`.
- После запуска приложение предлагает восстановить сессию; автоматическое воспроизведение без действия пользователя не выполняется.
- Сохранённая сессия валидируется по текущей медиатеке, удалённые и неиграбельные записи отбрасываются. Возобновление использует актуальную изменённую пользователем очередь, а не старый снимок.

### Backup & Restore
- Добавлены JSON-резервные копии метаданных: треки, тексты песен, плейлисты, избранное, история, общие настройки и пользовательская 10-полосная EQ-кривая.
- Формат версии 1, размер до 8 МиБ, лимиты коллекции и повторная проверка всех внешних ссылок.
- В резервную копию не входят аудиобайты; отсутствующие локальные файлы явно показываются при восстановлении.
- Восстановление обновляет метаданные существующих треков, объединяет избранное/плейлисты/историю и безопасно возвращает допустимые ссылки. Legacy URL платформ преобразуются в закладки; недопустимые старые ссылки не блокируют экспорт всей копии.

### Update & Release Pipeline
- Проверка обновлений при запуске и вручную по двум публичным источникам: стабильный JSON-манифест и GitHub Releases.
- Строгая проверка SemVer `MAJOR.MINOR.PATCH`; некорректные версии/пререлизы не трактуются как стабильное обновление.
- Тайм-аут запросов, ограничение размера ответа, отказ от credentials и перенаправлений, белый список доменов.
- Уведомление ведёт только на официальный GitHub Releases. Автоматической или скрытой установки нет.
- CI проверяет версионную согласованность, выполняет тесты, Rust formatting и строит оба Windows-установщика.
- Release workflow проверяет тег `v2.0.0`, создаёт GitHub Release с EXE/MSI и обновляет `public/version.json`.

### Исправления надёжности
- Удалено дублирующее объявление `deleteSelectedTracks`, из-за которого Node.js синтаксическая проверка и Windows pipeline завершались с ошибкой до сборки.
- Введена единая строгая проверка версии из npm, Cargo, Tauri и HTML вместо устаревших литералов в smoke-тестах.
- Сохранены предыдущие функции 1.7–1.9: 10-band EQ, 26 платформ, тексты TXT/LRC, MediaSession, CORS-safe direct streams, очередь, история, плейлисты и Library Studio.
- Исправлено пакетное добавление в очередь: уже прослушанный префикс не воспроизводится повторно, готовая очередь запускается кнопкой Play с любой страницы, Shuffle перемешивает только будущие треки.
- Исправлена сетка строк главной страницы: записи без чекбокса больше не резервируют узкую колонку выбора.
- **BAT-файлы не изменялись.**
