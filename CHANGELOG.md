# История изменений QWEMU MUSIC Desktop

## 1.9.0 — Library Studio & Batch Actions

### Новое
- Массовый выбор композиций в медиатеке, избранном, очереди, истории и открытом плейлисте.
- Пакетное добавление отмеченных треков в очередь, плейлист и избранное; повторные элементы не дублируются.
- Экспорт выбранных записей в M3U8 без включения аудиофайлов в текстовый плейлист.
- Пакетное удаление через одну транзакцию IndexedDB с синхронной очисткой избранного, истории, очереди и плейлистов.
- Ctrl+A выбирает видимые треки, Esc снимает выделение; панель массовых действий адаптирована для узких окон.
- Главная страница показывает объём локального аудиохранилища вместе с другими показателями медиатеки.

### Надёжность
- Добавлен отдельный модуль управления выделением с лимитом 5000 ID и очисткой повторных/недействительных значений.
- Добавлен атомарный метод `LibraryStore.removeMany`; одиночное удаление использует тот же путь.
- Тесты покрывают переключение выделения, скрытые записи, лимиты и пакетное удаление.
- BAT-файлы не изменялись.

## 1.8.0 — Playback Reliability, Link Import & Platform Catalogue

### Исправления
- Устранена гонка при быстром переключении треков: устаревшая асинхронная загрузка из IndexedDB не начинает воспроизведение после выбора другой композиции.
- Остановка воспроизведения и закрытие окна инвалидируют ожидающие запросы аудио.
- Импорт файлов сериализован, поэтому одновременные действия не создают пересекающиеся записи и не обходят расчёт лимита медиатеки.
- Каталог добавления музыки расширен до 26 международных и российских платформ; список сервисов виден в окне импорта.
- Ссылки платформ сохраняются с provider ID и названием сервиса, дубликаты ссылок отклоняются до записи.
- Прямые cross-origin аудиопотоки воспроизводятся через отдельный HTMLAudioElement, не подключённый к Web Audio EQ-графу; локальное воспроизведение и эквалайзер остаются на основном элементе.
- Переключение громкости и mute синхронизируется между обоими аудиоканалами.
- Ошибка fingerprint или IndexedDB у одного файла больше не прерывает импорт остальных выбранных файлов; итоговое уведомление показывает добавленные, повторные, отклонённые и проблемные файлы.

### Совместимость и сборка
- Версия приложения синхронизирована в npm, Cargo, Tauri config и интерфейсе.
- Tauri Rust dependency закреплена на 2.12.7; обновление не включает автоматическую загрузку или установку.
- BAT-файлы не изменялись.


## 1.7.0 — Lyrics, Background & Link Update

### Новое
- Тексты песен: прикрепление TXT/LRC, редактирование и ограничение размера; LRC временные метки синхронизируют подсветку и seek.
- Фоновое воспроизведение по умолчанию, ручной переключатель и MediaSession actions (если поддерживаются).
- Добавление музыки по ссылке с проверкой HTTPS, разрешённых музыкальных сайтов и расширений прямых аудиофайлов.
- Ссылки на платформы сохраняются как закладки; прямые audio links могут воспроизводиться как потоки. Загрузка/извлечение защищённого контента не реализовано.
- QWEMU PLUS — демонстрационный экран (явно помечен DEMO, без подписок, платежей или реального каталога).
- Ручная проверка обновлений в свёрнутом разделе настроек; автоматического обновления нет.
- Расширены аудио-форматы, обновлены кнопки, логотип и дизайн плеера.

### Безопасность и совместимость
- HTTPS only, reject credential URLs, local addresses, unknown music-site domains and unsupported media extensions.
- LRC/TXT лимит 100 KiB, текст хранится локально.
- WebView2/кодеки определяют реальную поддержку некоторых контейнеров/кодеков.
- Проверка обновлений только по публичному GitHub API/manifest, без автозагрузки.

### Проверки
- Unit-тесты для LRC parsing, URL classification, audio format whitelist и IndexedDB link metadata.
- Smoke checks расширены.
- CI: frontend checks, unit/smoke, Rust formatting, Windows EXE/MSI build.
