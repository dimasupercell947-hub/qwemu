# QWEMU MUSIC 1.2.0 — ресурсы и пользовательские данные

- `web/index.html` — единственный исходник интерфейса, который Tauri упаковывает из `frontendDist: ../web`.
- `web/assets/` — обязательные CSS, JavaScript и фирменный SVG-логотип production-интерфейса. Не удаляйте ресурсы, на которые ссылается `web/index.html` или его скрипты.
- `web/superupdate-061.js` — совместимый модуль панели Studio Hub, резервного копирования и диагностики.
- `src-tauri/icons/qwemu-mark.ico` — иконка Windows-приложения.
- Импортированные композиции размещаются в каталоге данных QWEMU `music/`; `music/library.json` хранит метаданные, SHA-256 и пути.
- `music/library.json.bak` сохраняет предыдущую версию манифеста; исходные файлы пользователя не изменяются при простом сканировании библиотеки.
- SQLite хранит локальные данные API аккаунта/синхронизации. Миграция выполняется через проверенную временную копию.
- Существующие ключи `localStorage` и IndexedDB сохранены для совместимости; прежние Blob-копии используются как источник отката миграции.
- Резервная копия включает поддерживаемые пользовательские метаданные и настройки, но не музыкальные файлы, пароли, session tokens или локальные абсолютные пути.

Не удаляйте вручную каталог пользовательских данных QWEMU при обновлении. Перед миграцией или переустановкой сделайте резервную копию. См. `DATA_MIGRATION.md`, `PRIVACY_RU.md` и `LEGAL_RU.md`.
