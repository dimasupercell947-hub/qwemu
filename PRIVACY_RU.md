# QWEMU MUSIC 1.2.0 — политика обработки данных

## Где хранятся данные

- Локальные профили и настройки интерфейса остаются в хранилище WebView (`localStorage`).
- Старые музыкальные записи, импортированные предыдущими версиями, могут оставаться в IndexedDB браузера/WebView.
- Новые файлы, импортированные через нативный системный диалог, копируются в каталог данных QWEMU `music/`; исходные файлы пользователя не перемещаются.
- Метаданные нативной медиатеки находятся в `music/library.json`.
- Локальная SQLite база хранит данные API: аккаунты, сессии и синхронизируемый список метаданных.
- При миграции SQLite создаётся проверенная резервная копия; исходная база не удаляется.

## Сетевые обращения

- Desktop shell запускает Rust API на loopback-интерфейсе `127.0.0.1:8765`; это локальный API текущего процесса.
- Если пользователь выбирает онлайн-регистрацию или синхронизацию, соответствующие данные передаются на адрес API, который настроен для этой сборки. Не вводи персональные данные, если не доверяешь серверу.
- Локальные аудиофайлы автоматически не отправляются в облако.
- При открытии внешних URL или каталога Openverse браузер/WebView обращается к сторонним ресурсам; их операторы могут получать технические данные соединения по собственным правилам.

## Минимизация и безопасность

Не добавляй данные третьих лиц без законного основания. Используй уникальный пароль, не совпадающий с паролями других сервисов. Перед обновлением создавай резервную копию важных данных. Очистка данных WebView может затронуть локальные профили и старые IndexedDB записи.

## Ограничение документа

Документ описывает локальную архитектуру Stage 2 и не является универсальной политикой оператора публичного онлайн-сервиса. Перед публичным запуском серверной регистрации, аналитики, рекламы, облачной синхронизации или коммерческого обслуживания нужно определить оператора и цели обработки, подготовить необходимые уведомления/согласия и провести юридическую проверку применимых требований 152-ФЗ, включая требования к локализации, срокам хранения и безопасности.
